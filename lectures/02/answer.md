## 宿題

- 取り組んだレベル：発展（講座の用語集を LoRA で学習させ、用語集を検索する方式と比べる）
- 変えた設定やデータ：
  - 題材を架空 FAQ から講座の用語集（`data/glossary.json`・58 語）に替えた。入力は質問だけで、用語集は渡さない。定義をモデルの重みに覚えさせる設定にした。
  - 学習データは 132 件（`scripts/make_sft_dataset.py`）。用語集の 58 語を 2 通りの言い回しで聞く 116 件と、用語集に無い 8 語（Transformer・RLHF・Docker など）に「用語集に記載がありません。確認が必要です。」と `needs_review: true` で答える 16 件。
  - 評価は 26 問（`--eval` で作成）。学習と同じ言い回し（same）8 問、学習に無い言い回しや別名（reworded）10 問、用語集に無く学習にも使っていない語（ungrounded）8 問。評価用の語が学習データに入っていないことはスクリプト内で確かめている。
  - CONFIG は演習から 4 か所を変えた。`num_train_epochs` 10（170 ステップ）、`warmup_steps` 10、`max_seq_len` 768、`max_new_tokens` 320。定義は FAQ の回答より長いため、出力が途中で切れないようにした。LoRA の設定（r 16・alpha 32・lr 2e-4・量子化なし）は演習と同じ。
  - 比較のため、同じ 26 問を第3回のツール `search_glossary` で引いて同じ基準で採点した（`scripts/eval_glossary_lookup.py`）。検索結果の先頭の定義を答えとし、見つからなければ「確認が必要」とする。検索語は、質問から用語だけを取り出した場合と、質問文をそのまま使った場合の 2 通りを試した。

  - reworded で落ちたのは HITL・解答ファイル・stdio と Streamable HTTP の 3 問。HITL には MCP の定義を混ぜた文を返した。合格した PR（一致度 0.71）と Codespaces のシークレット（0.50）も、要の語は含むが、事実と違う文が混ざっていた。PR の回答には「本講座では用語集の作成をテストブランチで行う」という一文があった。

  - 検索方式は、用語だけを検索語にすれば 25/26 だった。外れたのは RAG で、「ファインチューニング」の定義の中の「RAG」に部分一致した。質問文をそのまま検索語にすると、Pi・PR・QLoRA・Codespaces のシークレット・stdio の 5 問で別の語に当たるか見つからず、21/26 に下がった。
- ファインチューニングが向く場面・向かない場面についての考察：
  - 用語の定義のように「正しい答えが文書にあり、更新される知識」は、ファインチューニングで覚えさせるより検索で渡す方が合っている。学習後のモデルは、学習した言い回しには定義をそのまま返せる。しかし、言い換えや知らない語に対して、講座の文体で誤った説明を作るようになった。誤りが本物の定義と同じ口調で出るので、読み手が見分けにくい。この点は学習前より悪くなっている。
  - 知らない語を断る練習として 8 語・16 件を入れたが、別の 8 語には 1 語しか効かなかった。断るべき語を数語見せても「用語集に無いものは断る」という規則にはならず、学習した語を覚えただけだった。断る判断はモデルの外（検索で見つからないこと）で決める方が確実である。
  - 検索方式は 58 語のうち該当する定義をそのまま返せる。用語集を直せばその場で答えも変わり、学習し直す必要が無い（学習は 1 回 14 分かかった）。弱点は検索語の作り方で、質問文をそのまま使うと 5 問外れた。部分一致で別の語の定義を返す誤りもある。ここはエージェントの LLM に用語を取り出させる、完全一致を優先するなどで補える。
  - ファインチューニングが効いたのは出力の形式で、学習前 0/26 から 26/26 になった。決まった JSON で返す、確認が必要なときの言い方をそろえる、といった「答え方」を教えるのに向いている。知識そのものは検索で渡し、形式や口調はファインチューニングで整える、という組み合わせが今回の結果からは妥当だと考える。
  - 条件の限界：モデルは 0.8B、評価は 26 問、1 回の実行だけである。より大きいモデルや多くのデータでは reworded と ungrounded の結果が変わる可能性がある。loss は 0.038 まで下がっており、定義を丸ごと覚えるところまで学習が進んでいた。エポック数を減らしたときに言い換えへの強さと断定の多さがどう変わるかは、確かめていない。
